# Actividad 1. Carga y exploración de datos con Python

## Descripción del proyecto

Este proyecto corresponde a una actividad introductoria de programación en Python, enfocada en la lectura y exploración de conjuntos de datos en formato CSV.

## Objetivo

Cargar un conjunto de datos, visualizar sus primeras filas e identificar sus características generales mediante Python.

## Herramientas utilizadas

- Python 3.11
- JupyterLab
- Pandas
- Git
- GitHub

## Conjunto de datos

Se utilizó un archivo CSV correspondiente a registros administrativos de una jornada de actividades de una cooperativa pesquera.

La información incluye registros de personas, insumos, cantidades, importes económicos, fechas y folios.

## Estructura del proyecto

- `notebooks/`: contiene el cuaderno de Python con el procedimiento y los resultados de la exploración.
- `data/`: directorio destinado al almacenamiento del conjunto de datos.
