# Actividad 2. Análisis exploratorio de datos pesqueros con Python

## Descripción

Esta actividad tiene como objetivo aplicar herramientas de Python para la exploración y visualización de una base de datos pesquera correspondiente a la localidad de Celestún, Yucatán.
Se trabajó con el archivo `hackaton_kact.xlsx`, que contiene registros relacionados con la actividad pesquera, incluyendo información temporal y datos de captura.

## Objetivos

- Explorar y organizar la información de la base de datos.
- Analizar la distribución temporal de las entrevistas pesqueras.
- Describir la composición de las capturas por especie.
- Desarrollar y aplicar funciones para automatizar cálculos.
- Representar los resultados mediante gráficas.

## Herramientas utilizadas

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Análisis realizados

**1. Distribución temporal de entrevistas**
Se analizaron los registros por año y mes mediante una tabla de frecuencias y un mapa de calor.

**2. Composición de las capturas**
Se agruparon las diferentes categorías comerciales correspondientes a una misma especie para calcular la captura total y su contribución porcentual.

**3. Desarrollo de funciones**
Se creó una función en Python para automatizar el cálculo de la composición porcentual de las capturas.

## Archivos del proyecto
- `Actividad_2_Analisis_Celestun.ipynb`: notebook con el código, procedimientos, tablas, gráficas y conclusiones.

## Consideraciones
Los resultados corresponden a los registros disponibles en la base de datos y deben interpretarse considerando sus limitaciones de cobertura y registro. La composición calculada incluye únicamente las categorías de especies consideradas en el análisis.
